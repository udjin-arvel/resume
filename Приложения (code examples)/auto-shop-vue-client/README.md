# Импорт автомобилей из Китая

Клиентское веб-приложение сервиса поставки автомобилей: публичная витрина для заказчика и личный кабинет для менеджера, который ведёт заявку от подбора до порта.

Часть [портфолио приложений](../README.md).

## Задача

Сервис продаёт не «каталог машин», а процесс: заявка, варианты, диагностика, бронь, инвойс, оплата, логистика. Интерфейс должен одинаково понятно вести клиента и сотрудника компании по этим этапам и давать публичные страницы, которые можно отправить ссылкой.

## Что внутри

- Лендинг этапов поставки, каталог, карточка автомобиля, отзывы, FAQ, контакты.
- Личный кабинет: заявки, объявления, бронирование, покупатель, инвойс и оплата, трекинг логистики.
- Отчёты диагностики и компенсации по публичной ссылке с кодом.
- Админка: компании-клиенты, расходы в Китае, калькулятор доставки, статистика уведомлений, проверки источников.
- Интерфейс на русском и китайском, SEO-страницы и карта сайта.
- Обновления кабинета по websocket (Laravel Echo).

## Стек

Nuxt 3, Vue 3, TypeScript, Pinia, Tailwind CSS, Vue I18n, TanStack Table, Sentry. Сборка и выкладка через Docker и GitLab CI.

## Запуск

```bash
npm install
npm run dev
```

Для локальной работы без автообновления токена: `NUXT_PUBLIC_AUTH_REFRESH_ENABLED=false`.
