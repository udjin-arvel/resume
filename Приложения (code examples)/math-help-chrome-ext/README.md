# Math Help

API расширения Chrome «Math Problem Solver»: скриншот задачи уходит на сервер, обратно приходит пошаговое решение.

Часть [портфолио приложений](../README.md).

В этом каталоге — сервер. Само расширение ходит сюда с уже снятым скриншотом.

## Задача

Задачу на экране проще сфотографировать, чем переписывать в чат. Сервер принимает картинку, разбирает её моделью и отдаёт решение по фиксированному шаблону: условие, шаги, проверка, ответ. Бесплатные попытки кончаются, дальше доступ идёт через подписку.

## Что внутри

- `POST /image/upload`: URL скриншота, язык и режим `fast` или `complex`. Ответ — поток SSE.
- Промпт с жёстким шаблоном решения и формулами в LaTeX.
- Вход через Google и JWT. Баланс попыток и подписка лежат у пользователя.
- Stripe: оформление, вебхук и отмена подписки в конце периода.
- Страницы успеха и отмены оплаты.
- Ежедневная сводка и проверка живости API в Telegram.
- Логи Winston, лимит запросов, healthcheck.

## Стек

NestJS, TypeScript, TypeORM, PostgreSQL, Stripe, OpenAI, Telegram Bot API, Winston. В проде — Docker Compose и nginx.

## Запуск

Нужны PostgreSQL и `.env`: база, `OPENAI_API_KEY`, ключи Google и Stripe.

```bash
npm install
npm run start:dev
```

Прод-сборка: `docker compose up --build` (`compose.yaml`, переменные из `.env.prod`).
