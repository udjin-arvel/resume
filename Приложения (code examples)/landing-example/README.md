# Bitcom

Одностраничный сайт выездного сервиса: ремонт и настройка компьютеров, ноутбуков, телефонов и сетевого оборудования.

Часть [портфолио приложений](../README.md).

## Задача

Небольшой сервис живёт на звонке и выезде. Странице достаточно за несколько экранов сказать, с чем работают, что диагностика бесплатная, и оставить телефон и адрес на виду. Без кабинета, каталога и лишней навигации.

## Что внутри

- Закреплённая шапка: логотип, контакты, адрес.
- Блоки услуг и преимуществ: выезд, оригинальные запчасти, срок приезда мастера.
- Вёрстка под десктоп и телефон на Tailwind.

Это пример посадочной страницы, а не продуктовое приложение.

## Стек

Vue 3, TypeScript, Vite, Tailwind CSS, Sass.

## Запуск

```bash
npm install
npm run dev
```
