# Студия контента для маркетплейсов

Веб-клиент, в котором продавец собирает визуал карточки товара: генерация изображений, апскейл, инфографика, фоторедактор и канвас из связанных шагов.

Часть [портфолио приложений](../README.md). Генерацию выполняет отдельный [backend-прокси](../proxy-python-app).

## Задача

Карточка на маркетплейсе — это не один промпт, а цепочка: исходник, правка, увеличение, инфографика, сравнение с конкурентами. Интерфейс должен держать эти шаги в одном рабочем месте и не заставлять выгружать файл в соседний сервис на каждом этапе.

## Что внутри

- Генерация изображений для карточек товаров.
- Повышение чёткости и увеличение без отдельного фоторедактора.
- Канвас сценариев: блоки и связи между действиями (React Flow).
- Разбор инфографики и описаний карточек конкурентов.
- Фоторедактор на Konva.
- Чат с моделью, галерея результатов, регистрация и вход.

Клиент собран по слоям Feature-Sliced Design: страницы, виджеты, фичи, сущности, общий код.

## Стек

React 19, TypeScript, Vite, Redux Toolkit, React Router, Ant Design, GraphQL (`graphql-request`, `graphql-ws`), XYFlow, Konva.

## Запуск

```bash
npm install
npm run dev
```
