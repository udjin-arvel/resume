# Городские камеры

Веб-клиент просмотра уличных камер: карта города, живое видео и архив по выбранной камере.

Часть [портфолио приложений](../README.md).

## Задача

Камер в городе много, а смотреть их по списку неудобно. Экран строится вокруг карты: точка на районе, попап, плеер. Для своих камер есть отдельный вход; публичный список и личный набор живут в одном интерфейсе.

## Что внутри

- Карта на Leaflet с попапами камер.
- Плеер Video.js для живого потока.
- Архив конкретной камеры.
- Фильтры и выбор города.
- Вход и разделение маршрутов «все камеры» и «мои камеры».

## Стек

Vue 3, Vue Router, Vuex, Video.js, Leaflet, Bootstrap, Axios.

## Запуск

```bash
npm install
npm run serve
```
