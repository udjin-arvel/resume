# ScanMe

Мобильное приложение, которое по штрих-коду показывает состав продукта и объясняет, какие добавки считаются спорными. Рядом — API и веб-админка справочника веществ.

Часть [портфолио приложений](../README.md).

## Задача

Покупатель в магазине не будет читать E-добавки в справочнике. Скан должен за секунды дать название, состав и короткую причину, почему компонент отмечен. Справочник при этом ведут люди, а не только открытая база: админка нужна, чтобы поправлять объяснения и не зависеть целиком от Open Food Facts.

## Что внутри

Монорепозиторий из трёх частей:

```
app/         Flutter, iOS и Android
backend/     Go REST API
dashboard/   React-админка
```

- Сканирование EAN-13, UPC и QR, история и избранное.
- Поиск продукта в Open Food Facts, кэш, разбор состава по справочнику вредных веществ.
- Лимит бесплатных сканов и подписка.
- Админка: CRUD по веществам и аналитика.

## Стек

Flutter, Material 3, Riverpod, go_router. Go, chi, PostgreSQL, Redis, JWT. React, Vite, TypeScript, TanStack Query.

## Запуск

```bash
cd backend && go run ./cmd/api
cd app && flutter pub get && flutter run
cd dashboard && npm install && npm run dev
```

API по умолчанию: http://localhost:8080 (`/healthz`).
