# Radar CRM

Mini CRM для полевых команд: проекты и объекты, работники, сметы, финансы, инструменты и отчёты. Открывается в браузере и как Telegram Mini App.

Часть [портфолио приложений](../README.md).

## Задача

Менеджеру объекта нужен один экран, с которого видно, что горит сегодня: новые заявки людей, отчёты на проверке, простои, просрочки, инструмент. Работнику — узкий мобильный контур: свои проекты, отчёты и документы. Telegram выбран как привычная точка входа, обычный вход по почте остаётся для работы вне мессенджера.

## Что внутри

- Роли менеджера, работника и супервайзера, онбординг и одобрение регистрации.
- Вход через email и пароль или через `initData` Telegram WebApp, JWT.
- Проекты и клиенты, назначения на объект, уведомления команде.
- Сметы с конструктором блоков, шаблонами и выгрузкой в PDF и XLSX.
- Недельные отчёты работников и ежедневные отчёты супервайзера, включая расшифровку голосового сообщения.
- Зона работника: проекты, отчёты, документы, профиль.

## Стек

Go (Gin), PostgreSQL, React, TanStack Start и TanStack Query, Telegram Bot API, Docker.

## Структура

```
backend/    REST API
client/     веб-клиент и Telegram Mini App
```

## Запуск

```bash
copy .env.example .env
docker compose up -d
```

Фронтенд: `cd client && npm install && npm run dev` — http://localhost:3000. API: http://localhost:8080/health.
