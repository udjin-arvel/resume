# TheBook

Сайт-книга: истории, главы, понятия, лор и заметки одной вымышленной вселенной. Читать можно без аккаунта, писать и править — после входа.

Часть [портфолио приложений](../README.md).

## Задача

Обычный блог плохо держит вселенную: персонажи, места и главы расползаются по разным постам. Здесь контент связан типами, у читателя есть уровень и опыт, часть историй открывается по мере роста, а отдельные заметки — за внутренние токены. Это читательский продукт с правилами игры, а не вики на движке.

## Что внутри

- Истории и композиции (книга или набор глав), фрагменты текста.
- Понятия (персонаж, место, объект, событие), элементы лора, заметки.
- Комментарии, правки к тексту, достижения и задания с наградой.
- Профиль, уровни доступа к историям, платные заметки за токены.
- Клиент: чтение, фильтры, редактор Quill, боковое меню и модалки (шрифт, ошибка в тексте, быстрый словарь).
- Сервер: пользователи, роли, JWT, опыт и токены, загрузка изображений.

## Стек

Nuxt 4, Vue 3, Tailwind CSS, Vuetify, Pinia. Node.js, Express, Prisma, PostgreSQL.

## Структура

```
app/       клиент
server/    API
```

## Запуск

Клиент: `npm install && npm run dev` в корне приложения.

Сервер: скопировать `.env`, поднять PostgreSQL, затем `npm install`, `npm run db:migrate`, `npm run dev` в `server/`.
