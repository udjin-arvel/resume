TheBook - сайт-книга.

Описание сайта:  
Сайт представляет собой набор историй, книг и понятий в рамках одной вселенной. 
На сайте можно авторизовываться. Неавторизованные пользователи могут читать истории и просматривать контент, но не могут добавлять, удалять и редактировать что-либо.

Авторизованные пользователи могут добавлять контент (истории, композиции, понятия, элементы лора, заметки), оставлять комментарии к контенту. Добавлять исправления к контенту. У пользователей есть уровень и опыт. Опыт растет при добавлении любого контента (кол-во опыта разное для разного контента). В зависимости от уровня, пользователю открывается более высокого уровня истории.

Также на сайте есть система внутренних токенов, за которые пользователь может открыть "платный контент", который представляет из себя заметку с секретами или особенностями вселенной. Также есть различные достижения, например, достижение Опытный писатель "Пользователь написал 10 историй".

Примерное описание структуры базы данных:
Таблица с пользователями (users) имееет поля: login, status (админ, модератор, писатель или читатель), email, password, token, info, level, experience, tokens.

Таблица с копозициями (compositions) имеет поля: title, user_id, parent_id (запись может ссылаться на такую же composition), description, type (полноценная книга или набор глав), poster, is_public.

Таблица с историями (stories) имеет поля: title, user_id, composition_id (может не принадлежать композиции), type (история или анонс), chapter, access_level, epigraph, is_public, notes (json, массив названий или имен внутри истории в виде памятки).

Таблица с фрагментами (fragments) имеет поля: story_id, order (порядок в истории), text. Фрагменты обычно состоят из нескольких абзацев, но могут быть достаточно массивными. Также следует предусмотреть, что к фрагменту можно будет прикреплять коментарий автора, музыкальный трек или изображение.

Таблица с понятиями (notions) имеет поля: title, user_id, text, poster, type (это может быть: Определение, Персонаж, Место, Объект, Сущность, Событие), access_level, is_public.

Таблица с элементами лора (loreitems) имеет поля: title, user_id, text, poster, access_level, is_public.

Таблица с заметками (notes) имеет поля: title, user_id, text, price (по умолчанию 10), importance, is_content. Заметку можно превратить в платный контент (is_content), который другие пользователи могут "купить" за токены.

Таблица с заданиями (tasks) имеет поля: title, description, tokens, experience, is_public. Задания может создавать только админ. Задания дают награду пользователю за выполнение в виде токенов и опыта.

Таблица с изображениями (images) имеет поля: path, title, user_id, content_id, content_type. Изображения можно дополнительно постерам добавлять к таким моделям, как composition, story, fragment, notion, loreitem.

Каждая таблица имеет поле id и даты создания/редактирования.
