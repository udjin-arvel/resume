# Conquer

Сервис разбора сайта конкурента: ссылка на страницу, съём содержимого, разбор моделью, метрики и короткая сводка.

Часть [портфолио приложений](../README.md).

## Задача

Ручной разбор чужого лендинга занимает больше времени, чем сам вывод. Conquer забирает страницу, вытаскивает структуру и отдаёт отчёт, который можно прочитать без исходного HTML. Тяжёлая работа — браузер и запрос к модели — не блокирует HTTP: она уходит в очередь.

## Что внутри

- Форма с URL и страница статуса заявки.
- Съём страницы через Playwright.
- Анализ через DeepSeek: метрики и текстовая сводка.
- Фоновый прогон «спарсить и разобрать» в Celery.
- Простой веб-интерфейс на серверных шаблонах, без отдельного SPA.

Прототип экранов лежит в `.lovable`.

## Стек

Python, FastAPI, Jinja2, PostgreSQL, SQLAlchemy, Alembic, Redis, Celery, Playwright, DeepSeek API.

## Запуск

```bash
cp .env.example .env
docker compose up --build
```

Интерфейс: http://localhost:8000. В `.env` нужен `DEEPSEEK_API_KEY`.
