# Прокси к моделям генерации

Backend, через который клиент студии контента ходит в языковые и медиамодели. Наружу торчит один HTTP API: текст, изображения и видео, без ключей провайдеров в браузере.

Часть [портфолио приложений](../README.md). Интерфейс студии — [media-generator-react-client](../media-generator-react-client).

## Задача

Промпт для карточки товара нельзя отдавать модели «как написал пользователь». Сервис собирает жёсткую спецификацию правки (что менять и что запрещено), из неё — финальный промпт под конкретную модель, и только потом запускает генерацию. Так видеообложка, примерка и перенос объекта ведут себя предсказуемо.

## Что внутри

- FastAPI-приложение и веб-формы для ручной проверки сценариев.
- Слой OpenAI: текст и сборка спецификации правки.
- Слой генерации медиа (Runway и Atlas-модели): изображения и видео.
- Промпт-сервис: шаблоны, негативные правила, сборка запроса из спецификации.

## Стек

Python, FastAPI, Pydantic, OpenAI API, Runway API.

## Запуск

```bash
pip install -r requirements.txt
copy .env.example .env
uvicorn main:app --host 0.0.0.0 --port 8090 --reload
```

В `.env` нужны ключи провайдеров. Без них API поднимется, генерация — нет.
