# FoodSource — smoke-test

Быстрая проверка прототипа (~10–15 мин). Отметьте пункты по мере прохождения.

**Предусловия:** Docker (или локально API + client), браузер Chrome/Edge/Firefox.

---

## 0. Поднять стек

```bash
make up
# или: docker compose up --build
```

| Проверка | Ожидание |
|----------|----------|
| UI открывается | http://localhost:8080 — заголовок FoodSource, список поставщиков |
| API жив | http://localhost:8000/health → `{"status":"ok"}` |
| Swagger | http://localhost:8000/docs открывается |
| Нет бейджа «Демо-данные» в шапке | Клиент ходит в API (не in-browser mock) |

**CLI (опционально):**

```bash
make health
make test
```

`make test` — 17 pytest + 13 vitest; падение = стоп до фикса.

## 1. API (2 мин)

```bash
curl -s "http://localhost:8000/meta" | head -c 200
curl -s "http://localhost:8000/suppliers?page_size=2"
```

| # | Действие | Ожидание |
|---|----------|----------|
| 1.1 | `GET /meta` | `categories` (3), `regions`, `cities`, `units`: кг, шт, упак |
| 1.2 | `GET /suppliers?category=ingredients&region=Сибирский%20ФО&has_certificates=true` | `total` ≥ 1, у items совпадают фильтры |
| 1.3 | `GET /suppliers?brief_category=ingredients&page_size=50` | Ровно один item с `rank_badge`: `"best"`, у items есть `score` и `score_reasons` |
| 1.4 | `POST /compare` body `{"ids":[1,7]}` | `200`, в `best.price_per_unit` — id с меньшей ценой (мука vs крахмал) |
| 1.5 | `POST /recommend` body `{"category":"packaging","need_certificates":true}` | `items` length 3, `explanation` не пустой |

Пример compare (PowerShell):

```powershell
curl.exe -s -X POST http://localhost:8000/compare -H "Content-Type: application/json" -d "{\"ids\":[1,7]}"
```
