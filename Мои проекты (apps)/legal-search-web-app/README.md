# Поиск по кодексам

Мобильное приложение: полнотекстовый поиск по статьям УК, ТК, КоАП, ГК и НК. Результат открывается сразу, без сайта КонсультантПлюс и без листания PDF.

Часть [портфолио приложений](../README.md).

## Задача

Нужная статья обычно известна по паре слов, а не по номеру. Приложение ищет по номеру, заголовку и тексту, сужает выдачу кодексом и показывает фрагмент с подсветкой совпадения. Избранное и последние запросы остаются на устройстве: аккаунт для чтения не нужен.

## Что внутри

- Поиск с задержкой ввода, фильтром по кодексам и ранжированием выдачи.
- Карточка статьи: глава, текст по абзацам, копирование и «поделиться».
- Избранное на устройстве, удаление свайпом.
- История запросов и кэш последних результатов, чтобы повторный запрос открывался без сети.
- Тёмная тема по системе, тактильный отклик, скелетоны и повтор при ошибке сети.
- На экране статьи пометка, что текст не официальный источник.

Поиск живёт в Postgres: `tsvector` по-русски, GIN-индекс и RPC `search_articles` с `ts_rank` и `ts_headline`. Клиент ходит только в этот RPC и в чтение таблиц.

Прототип экранов лежит в `.lovable`.

## Стек

React Native, Expo SDK 57, TypeScript, React Navigation, Zustand, AsyncStorage. Supabase: PostgreSQL, полнотекстовый поиск, Row Level Security. Сборка — EAS (Android и iOS).

## Запуск

```bash
npm install
cp .env.example .env
npm start
```

В `.env` нужны `EXPO_PUBLIC_SUPABASE_URL` и `EXPO_PUBLIC_SUPABASE_ANON_KEY`. Схема базы — в `supabase/migrations`. Сборка: [docs/BUILD.md](docs/BUILD.md).
