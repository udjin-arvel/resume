# HH-Hunter

Расширение Chrome: открыл вакансию на HeadHunter — получил сопроводительное письмо под свой опыт, а не общий шаблон.

Часть [портфолио приложений](../README.md).

## Задача

Отклик на hh.ru ломается на одном и том же месте: вакансия уже открыта, а письмо каждый раз пишется заново. Расширение читает вакансию, сверяет её с локальным профилем и собирает письмо в боковой панели, не уводя соискателя с сайта.

## Что внутри

- Импорт вакансии по ссылке hh.ru через публичный API.
- Профиль с достижениями и необязательным импортом портфолио по URL. Профиль хранится в браузере.
- Настройка тона и длины.
- Три блока ответа: скрытые ключи вакансии, точка пересечения с опытом, готовое письмо.
- Копирование текста и переход к отклику.
- Сборка под Chrome и Firefox, тесты, линтер, проверка типов.

Ключ модели используется в background service worker, не в содержимом страницы.

## Стек

WXT, Chrome Extension Manifest V3, React 19, TypeScript, Zustand, Zod, Tailwind CSS, Vitest. Генерация текста — DeepSeek API.

## Запуск

```bash
cp .env.example .env
npm install
npm run dev
```

В Chrome: `chrome://extensions`, режим разработчика, загрузить `.output/chrome-mv3`. В `.env` нужен `WXT_DEEPSEEK_API_KEY`.
